# OMNINA — Personal Design Studio

A personal design studio website designed and developed from scratch, combining editorial visual direction, responsive UI and custom JavaScript interactions.

## Overview

Omnina is a personal design studio website created to present selected design work through a visually focused and interactive digital experience.

The project combines UI design, typography, layout and front-end development, with custom interactions built to support the visual identity of the studio.

## Role

**UI Design · Web Design · Front-end Development**

## Tools

**Figma · HTML · CSS · JavaScript · Visual Studio Code**

## Key Features

- Responsive web design
- Editorial typography-led layouts
- Custom JavaScript interactions
- Scroll-based animations
- Hover interactions
- Interactive transitions
- Responsive navigation
- Multi-page website structure

## Process

**Figma → UI Design → HTML/CSS → JavaScript → Final Implementation**

The interface was first designed in Figma and then translated into a responsive website using HTML and CSS. JavaScript was used to add custom interactions, animations and transitions throughout the experience.

## Structure

The website is organised into four main sections:

- **Home** — introduction and selected work
- **Work** — project overview and selected projects
- **About** — studio and designer information
- **Contact** — contact information

## Development

The website was coded from scratch using semantic HTML, CSS and vanilla JavaScript.

The implementation focuses on maintaining the original visual direction while adapting the layouts and interactions for different screen sizes.
